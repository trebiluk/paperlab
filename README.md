# BertyBot's PaperLab

Paper technology labs for Solvay Middle School Tech Ed — one sheet of paper, scissors, glue, a period.

Live door: [The Tech Room](https://apps.kulibert.net) · this app deploys as **paperlab**. Skills and Gold XP practice here; the 1–4 mark lives in [TechWorks](https://tw.kulibert.net).

## Classroom

Grades 2–8 · NYSED MST Standard 5 · Easy / Class / Stretch reading · ELL frames · helper cards.

Eight shop skills (Safety, Measure, Draw, Model, Tools, Finish, Present, Team). Mark a lab made on a Chromebook and it counts as Gold XP — Cub through Legend, same bands as the desk. Print a Watch slip (no name) and tap 1–4 in TechWorks.
